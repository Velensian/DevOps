  1. Код возврата - каждая программа в Linux при завершении сообщает системе число, код возврата.
    1. 0 - все прошло нормально и успешно
    2. Либое лругое число - “Что-то пошло не так”, разные чила, разные ошибки

Этот код не выводится на экран, а хранится в специальной оболочке $?. Просмотреть ее можно через команду echo $?

Ключ $? запоминает только последнюю команду:

  • При cd ~  выполнится с кодом 0(успех)

  • Далее при $? выполнится команда 0 с кодом 127(Ошибка - комаенда не найдена)

  • Далее при cd /book выполнится я с кодом 1(Ошибка - нет такой директории)

  • Далее при $? - выполнится команда 1 с прошого кода и завершится с кодом 127(Ошибка - команда не найдена)
