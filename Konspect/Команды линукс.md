### Конспект: базовые команды Linux

**Где я и что вокруг**

| Команда | Что делает | Пример |
| --- | --- | --- |
| `pwd` | показывает текущую папку (**p**rint **w**orking **d**irectory) | `pwd` → `/home/velensis/devops` |
| `ls` | содержимое папки; `-l` подробно, `-a` со скрытыми | `ls -la` |
| `cd` | перейти в папку; `..` вверх, `~` домой | `cd ~/devops` |

**Файлы и папки**

| Команда | Что делает | Пример |
| --- | --- | --- |
| `mkdir` | создать папку | `mkdir notes` |
| `touch` | создать пустой файл | `touch day3.md` |
| `cp` | копировать: откуда → куда | `cp a.py b.py` |
| `mv` | переместить или переименовать | `mv old.md new.md` |
| `rm` | удалить файл (без корзины, навсегда!) | `rm tmp.txt` |

**Смотреть текст**

| Команда | Что делает | Пример |
| --- | --- | --- |
| `cat` | вывести файл на экран целиком | `cat README.md` |
| `less` | листать большой файл (выход `q`, поиск `/слово`) | `less log.txt` |
| `head` / `tail` | первые / последние 10 строк; `-n 50` задаёт число | `tail -n 50 log.txt` |
| `grep` | только строки с шаблоном; `-i` без учёта регистра | `grep -i error log.txt` |
| `wc -l` | посчитать строки | `wc -l log.txt` |

**Куда идёт вывод**

| Запись | Что делает |
| --- | --- |
| `команда` | вывод на экран |
| `команда > файл` | вывод в файл, файл перезаписывается |
| `команда >> файл` | вывод дописывается в конец файла |

**Процессы и службы** (уже знакомы): `ps aux` (все процессы), `pgrep`, `kill`, `systemctl`, `journalctl -u имя` (журнал службы).

**Если забыл, что делает команда:** `man grep` (полное руководство, выход `q`) или `grep --help` (краткая справка).

Главная идея: каждая команда делает одну маленькую вещь, а сложные задачи собираются из них. Сегодня мы учимся именно их соединять.

| - pipe(конвейер) - нужен чтобы вывод левой команды, обрабатывался правой от пайка командой

ps aux | grep systemd | ==grep -v grep== | wc -l     # 10 - Поиск всех процессов в системе со словом systemd, но при этом без учета слова grep(желтое)

*   ps aux              → все процессы  
    | grep systemd      → только строки, где есть "systemd" (11 строк, включая сам grep)  
    | grep -v grep      → из них только строки, где НЕТ "grep" (10 строк)  
    | wc -l             → посчитать строки: 10
