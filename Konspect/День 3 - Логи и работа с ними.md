1.  Поиск по файлу
    1.  Для поиска по файлу используем команду grep “слово которое ищем” “файл в котором ищем”.
        
        Если надо искать без учета регистра то grep -i “слово которое ищем” “файл в котором ищем”
2.  Команды:
    1.  journalctl -u myserver > log.txt - журнал логов записан в файл
    2.  grep error log.txt - выбраны строки  с error
    3.  journalctl -b | grep -i error | tail -n 3 - поиск по журнали системы всех строк где есть error и выводить последние 3 записи
