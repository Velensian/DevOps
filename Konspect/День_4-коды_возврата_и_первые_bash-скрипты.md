1.  <span style="--tn-background:#e64d4d;background-color:#e64d4d;">Код возврата</span> \- каждая программа в Linux при завершении сообщает системе число, код возврата.
    1.  0 - все прошло нормально и успешно
    2.  Либое лругое число - “Что-то пошло не так”, разные чила, разные ошибки

Этот код не выводится на экран, а хранится в специальной оболочке $?. Просмотреть ее можно через команду echo $?

Ключ $? запоминает только последнюю команду:

*   При cd ~  выполнится с кодом 0(успех)
*   Далее при $? выполнится команда 0 с кодом 127(Ошибка - комаенда не найдена)
*   Далее при cd /book выполнится я с кодом 1(Ошибка - нет такой директории)
*   Далее при $? - выполнится команда 1 с прошого кода и завершится с кодом 127(Ошибка - команда не найдена)

6.  #### Флаги из таблицы
7.  | Флаг | Расшифровка | Что делает | Пример |
    | --- | --- | --- | --- |
    | `-u имя` | **u**nit | только записи этой службы | `journalctl -u myapp` |
    | `-n 50` | **n**umber | только последние 50 строк | `journalctl -u myapp -n 50` |
    | `-f` | **f**ollow | «следить»: показать конец и дописывать новые строки в реальном времени, пока не нажмёшь `Ctrl+C` | `journalctl -u myapp -f` |
    
    `-n` и `-f` работают так же, как у знакомого `tail`: `tail -n 5 файл` и `tail -f файл`.
    
    #### Ещё полезные флаги
8.  | Флаг | Что делает | Пример |
    | --- | --- | --- |
    | `-b` | только с последней загрузки системы (**b**oot) | `journalctl -b -u myapp` |
    | `--since` | с определённого времени | `journalctl -u myapp --since "10 min ago"` или `--since "2026-11-25 21:00"` |
    | `-p err` | только сообщения уровня «ошибка» и серьёзнее (**p**riority) | `journalctl -u myapp -p err` |
    | `--no-pager` | вывести сразу в терминал, без листалки (удобно для `grep` и скриптов) | `journalctl -u myapp --no-pager \| grep -i port` |
